# 稼働率とMTBF・MTTR：スマホの「元気な時間と入院時間」で覚える計算

> **想定読者**: MTBF、MTTR、アベイラビリティなどアルファベットの計算式が出た瞬間に思考停止してしまう文系受験者  
> **省いたもの**: ワイブル分布による故障率曲線、バスタブ曲線の微積分理論  
> **所要時間**: 7分  
> **対象過去問**: 応用情報技術者 令和4年秋期 午前問14（※過去問道場で2回間違えた重要問題）

## 0. 一枚で：解く手順は必ずこの「3ステップ」！

稼働率の計算問題は、公式を覚えるのではなく **「時間の割合（比率）」** として解きます。

```mermaid
flowchart LR
    S1["【Step 1: 意味の分解】<br/>MTBF＝元気な時間<br/>MTTR＝修理時間"]
    --> S2["【Step 2: 全体で割る】<br/>稼働率 ＝<br/>元気 ÷ (元気 ＋ 修理)"]
    --> S3["【Step 3: 約分パズル】<br/>両方1.5倍なら<br/>分数ごと相殺で『変わらない』！"]
```

### 合言葉：『 ビー（B）は元気・アール（R）はリペア（修理） 』
- **MTBF** の `B` ＝ **Between（故障と故障の間＝元気に動いている時間！）**
- **MTTR** の `R` ＝ **Repair（修理・入院にかかっている時間！）**
- **稼働率** ＝ **「全体の時間のうち、元気に動いていた時間の割合」**

---

## 1. なぜその計算になるの？（数式を使わない言葉の理屈）

あなたが持っているスマホをイメージしてください。

```
[元気に動いている時間（MTBF）: 10時間] ── [修理・入院（MTTR）: 2時間]
|<────────────────── 全体の時間: 12時間 ──────────────────>|
```

このスマホがちゃんと使えた割合（稼働率）は：
$$\text{稼働率} = \frac{\text{元気な時間}}{\text{元気な時間} + \text{修理時間}} = \frac{10}{10 + 2} = \frac{10}{12} = \mathbf{\frac{5}{6}}$$

### 「MTBFとMTTRがともに1.5倍になった」とは？
- 元気な時間: $10 \times 1.5 = \mathbf{15時間}$
- 修理時間: $2 \times 1.5 = \mathbf{3時間}$

新しい稼働率は：
$$\frac{15}{15 + 3} = \frac{15}{18} = \mathbf{\frac{5}{6}}$$

👉 **「比率」を計算しているだけなので、両方が同じ倍率（1.5倍）で伸びても、約分したら元の割合に戻るため「まったく変わらない」のです！**

---

## 2. 小学生の分数パズルで見る証明

数式で書くと難しそうに見えますが、小学生の分数の「約分」そのものです。

$$\text{新しい稼働率} = \frac{1.5 \times \text{MTBF}}{(1.5 \times \text{MTBF}) + (1.5 \times \text{MTTR})} = \frac{1.5 \times \text{MTBF}}{1.5 \times (\text{MTBF} + \text{MTTR})}$$

- 分母と分子にある **「1.5」を約分でスパッと消す**：
$$= \frac{\text{MTBF}}{\text{MTBF} + \text{MTTR}}$$

👉 **元の式と完全に一致するため、答えは「変わらない」になります！**（計算時間：5秒）

## 4. 実際の過去問で腕試し

### 【午前過去問】令和4年秋期 午前問14
**【問題】**  
あるシステムにおいて，MTBFとMTTRがともに1.5倍になったとき，アベイラビリティ(稼働率)は何倍になるか。

- **ア**: $\frac{2}{3}$
- **イ**: 1.5
- **ウ**: 2.25
- **エ**: 変わらない

<details>
<summary>正解と5秒スピード解法を表示</summary>

**正解: エ**

**文系目線でのスピード解法:**
- 稼働率は「元気な時間 ÷ (元気＋修理)」という **比率（割合）**。
- 分母も分子も同じ「1.5倍」になったら、分数の約分で1.5同士が綺麗に打ち消し合って消えます！
- したがって何倍にもならず、**「エ: 変わらない」** が正解です！
</details>
