## 【対象過去問】令和5年秋期 午前問80

**【問題】**  
図は，企業と労働者の関係を表している。企業Bと労働者Cの関係を表す記述として正しいものはどれか。

```
       [ 企 業 Ａ ] ────── (契 約) ────── [ 企 業 Ｂ ]
           │                                    │
       (雇用関係)                               │
           │                                    │
           ▼                                    ▼
       [ 労働者Ｃ ] <────────────────────── ( ？ )
```

- **ア**: "契約"が請負契約で，企業Aが受託者，企業Bが委託者であるとき，企業Bと労働者Cとの間には，指揮命令関係が生じる。
- **イ**: "契約"が出向にかかわる契約で，企業Aが企業Bに労働者Cを出向させたとき，企業Bと労働者Cとの間には指揮命令関係が生じる。
- **ウ**: "契約"が労働者派遣契約で，企業Aが派遣元，企業Bが派遣先であるとき，企業Bと労働者Cの間にも，雇用関係が生じる。
- **エ**: "契約"が労働者派遣契約で，企業Aが派遣元，企業Bが派遣先であるとき，企業Bに労働者Cが出向しているといえる。

**正解: イ（"契約"が出向にかかわる契約で，企業Aが企業Bに労働者Cを出向させたとき，企業Bと労働者Cとの間には指揮命令関係が生じる。）**

</details>

## 0. 一枚で：3大契約の「雇用」と「指揮命令」マトリクス！

客先で働く契約は、**「誰が給料を払い、誰が指示を出すか」** の違いしかありません。

| 契約の種類 | 誰と雇用関係がある？ | 現場で【指揮命令】できるのは誰？ | 違反するとどうなる？ |
| :--- | :--- | :--- | :--- |
| **請負（受託）** | **自社（企業A）だけ** | **自社（企業A）だけ！**（客先Bは指示NG） | 客先Bが直接「これやって」と指示すると **「偽装請負」で違法！** |
| **労働者派遣** | **派遣元（企業A）だけ** | **派遣先（企業B）ができる！** | 派遣先Bと労働者Cの間に「雇用関係」はない |
| **出向（在籍出向）** ★ | **AとBの【両方】** | **出向先（企業B）ができる！** | 正式なグループ移動なので、**Bから直接指示が出る（イが正解！）** |

## 1. なぜ「請負でお客さんが指示する」と違法なの？（偽装請負の罠）

IT業界で一番トラブルになり、試験で最も狙われるのが **「偽装請負」** です。

- **ピザのデリバリー（請負）をイメージしてください**:  
  ピザ屋（企業A）にピザ（成果物）を注文した客（企業B）が、配達に来た店員（労働者C）に対して「ついでに部屋の掃除して！皿洗いもして！」と直接指示（指揮命令）することは絶対にできませんよね。
- **指示していいのは「派遣」か「出向」だけ**:  
  客先Bが労働者Cに「これやって、あれやって」と直接指示を出したいなら、派遣契約を結ぶか、会社間で「出向」させなければいけません。

👉 したがって、出向させたときは当然 **「出向先企業Bと労働者Cの間に指揮命令関係が生じる（イ）」** が正しい記述です！

## 2. 選択肢のひっかけ見分け判定

- **ア: 請負なのに客先Bが指示できる？**  
  $\rightarrow$ **絶対にダメ！** 指揮命令が生じたら「偽装請負」という法律違反です（×）
- **イ: 出向のとき、出向先Bが指示できる？（正解！）**  
  $\rightarrow$ 出向先で働くのだから、当然 **企業Bから指揮命令を受けます**（◯★）
- **ウ: 派遣のとき、派遣先Bとも雇用関係が生じる？**  
  $\rightarrow$ 派遣先Bとは「指揮命令」だけ。給料を払う雇用関係は派遣元Aだけです（×）
- **エ: 派遣が出向といえる？**  
  $\rightarrow$ 派遣と出向は全く別の契約形態です（×）
