## 0. 一枚で：IPsecの「2大ボディーガード」！

IPsecは、**インターネットの道路（ネットワーク層・3階）** を安全な専用トンネル（VPN）にするための技術です。  
その中には、**性格の違う2人のガードマン** がいます。

```
┌────────────────────────────────────────────────────────┐
│ 【IPsec の2大プロトコル】                              │
│                                                        │
│  ① ＡＨ (Authentication Header: 認証ヘッダー)          │
│     👉【改ざん防止の封蝋印鑑】                        │
│     ※「改ざんされていないこと（完全性・認証）」だけを │
│        保証する。暗号化はしない（中身は丸見え）！      │
│                                                        │
│  ② ＥＳＰ (Encapsulating Security Payload: 暗号ペイロード)│
│     👉【中身を隠す頑丈な金庫】                        │
│     ※「盗聴防止（暗号化）」＋「改ざん防止（認証）」   │
│        の両方をこなす万能ガードマン！                  │
└────────────────────────────────────────────────────────┘
```

👉 **合言葉：『 AHは認証だけ、ESPは暗号もバッチリ！この2人＝IPsec！ 』**

## 1. なぜ「ネットワーク層（IP）」で動くのが偉いの？

セキュリティの仕組みは、動く「階層」が違います：

- **アプリケーション層（7階）のガードマン（S/MIME, SSH, HTTPS）**:  
  メールソフトやWebブラウザなど、**個々のアプリごとに設定が必要**。
- **ネットワーク層（3階）のガードマン（★IPsec）**:  
  ネットワークの土台（IP）で全部まとめて暗号化してくれるので、**上に乗っているアプリ（Web、メール、ファイル共有など）は何も意識しなくてOK！**

そのため、本社と支社をインターネット越しに安全に直結する **「インターネットVPN」** の主役としてIPsecが広く使われています。

## 2. 選択肢のプロトコルたちの所属部屋（消去法）

- **ア: IPsec（正解！）**:  
  $\rightarrow$ **ネットワーク層（3階）** で動作！**AH（認証）** と **ESP（暗号化）** を含む！
- **イ: S/MIME**:  
  $\rightarrow$ **電子メール（アプリケーション層）** を暗号化・電子署名するプロトコル。
- **ウ: SSH**:  
  $\rightarrow$ リモートログイン用（トランスポート層〜アプリケーション層）。
- **エ: XML暗号**:  
  $\rightarrow$ XMLデータの一部または全体を暗号化する技術（アプリケーション層）。
