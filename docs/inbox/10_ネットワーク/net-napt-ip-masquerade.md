## 1. なぜそうなるのか？（日常のたとえ話：会社代表電話（外線）に「内線番号（ポート番号）」を足して同時通話）

IPv4アドレスは世界中で約43億個しかなく、とっくに枯渇しています。
もし家族4人のスマホ・PC全員に1人1個ずつグローバルIPを配っていたら、全然足りませんよね。

そこで活躍するのが **NAPT（Network Address Port Translation）** です。
別名 **IPマスカレード** とも呼ばれます。

会社の電話に例えてみましょう：
- 会社の代表電話番号（外線番号）は **1つだけ**（グローバルIP）
- 社員ごとの「内線番号（ポート番号）」を後ろにくっつける

こうすれば、外からは1つの電話番号に見えても、内線番号を切り替えることで **何十人もの社員が同時に外と電話（ネット通信）** できます！

## 2. 選択肢のひっかけポイント ＆ 判定理由

- **ア: DHCP** → IPアドレスを自動で割り当てる仕組みです（×）。
- **イ: IPマルチキャスト** → 特定グループの複数端末へ同時に一斉送信する仕組みです（×）。
- **ウ: NAPT 【正解！】** → ポート番号を利用して1つのグローバルIPを複数端末で共有します（◯）。
- **エ: VPN** → 仮想的な専用トンネルを構築する技術です（×）。
