- **ア**: `2001:db8::3ab::ff01`

## 0. 一枚で：3秒で解ける「消去法フローチャート」

試験本番でIPv6の表記問題が出たら、計算は一切不要です！この順序で選択肢を消していくだけです。

```
【ステップ1】ドット「.」が入っている選択肢をゴミ箱へ！
  → IPv6は「コロン :」だけ！ドットはIPv4の遺物！
  （これで ウ・エ が即死）

【ステップ2】「::（ダブルコロン）」が2箇所以上ある選択肢をゴミ箱へ！
  → 「::」は住所の中で絶対に【1回だけ】！
  （これで ア が即死）

【ステップ3】残った1つ（イ）が正解！
```

## 1. なぜ「::」を2回使うとダメなの？（小学生の引き算パズル）

IPv6アドレスは、全部で **8個のブロック（部屋）** が並んでいます。

```
[1] : [2] : [3] : [4] : [5] : [6] : [7] : [8]  ← 全部で8部屋！
```

ゼロばかりの部屋が続くと書くのが面倒なので、**「::」でひとまとめにして省略していいよ** というルールがあります。

### 1回だけ使った場合（引き算で確実に元に戻せる！）
例えば `2001:db8::3ab:ff01` と書かれていたとします。

- 目に見えている部屋を数えると：  
  `2001`（1個目）、`db8`（2個目）、`3ab`（3個目）、`ff01`（4個目）の **合計4部屋** 見えています。
- 全体で8部屋あると知っているので、引き算をします：  
  $$8 - 4 = \mathbf{4部屋}$$
- **「あ、省略された `::` の中には、0の部屋が4個埋まっているんだな！」** と小学生の引き算で誰でも100%復元できます！

### 2回使った場合（引き算ができず迷子になる！）
もし `2001:db8::3ab::ff01`（アの選択肢）と書かれたらどうなるでしょうか？

- 目に見えている部屋は4部屋です。
- 省略された部屋の合計は $8 - 4 = 4部屋$ です。
- **でも、左の `::` に何部屋あって、右の `::` に何部屋あるのか誰にも分かりません！**
  - 左に3部屋、右に1部屋？
  - 左に2部屋、右に2部屋？
  - 左に1部屋、右に3部屋？

👉 **元の正しい住所に復元できないので、全世界のインターネット共通規格（RFC）で「2回使うことは絶対に禁止」と決められています！**

---

## 2. 選択肢のスピード判定まとめ

1. **ウ・エを消去**: ドット `.` が混ざっているので即アウト！（IPv6はコロン `:` だけ）
2. **アを消去**: `::` が2回使われているので即アウト！（$8 - 4$ の引き算が壊れて復元できない）
3. **イが正解**: コロン区切りで、`::` も1回だけ正しく使われています。
