## 1. なぜそうなるのか？（日常のたとえ話：新聞の配達員が「今日の朝刊の見出し一覧」をポストに入れてくれる仕組み）

毎日10個のニュースサイトを1つずつ巡回して、「新しい記事が上がっていないかな？」と手動でF5連打して確認するのは大変ですよね。

そこで生まれたのが **RSS** です。

Webサイト側が、記事を公開するたびに：
> 「今日の12時に『〇〇のニュース』を公開しました。概要はこんな感じです。リンクはこちら！」

という要約データを、コンピュータが読みやすい **XML形式** で配ってくれます。
私たちは「RSSリーダー」というアプリに登録しておくだけで、サイトを見に行かなくても更新情報が自動で手元に届きます！

---

## 2. 選択肢のひっかけポイント ＆ 判定理由

- **ア: BPEL** → ビジネスプロセスを実行・連携させるためのXML言語です（×）。
- **イ: RSS 【正解！】** → Webサイトの見出しや要約などの更新情報を配信するXMLフォーマットです（◯）。
- **ウ: SOAP** → ネットワーク経由でプログラム同士がXMLメッセージをやり取りする規約です（×）。
- **エ: WSDL** → Webサービスがどんな機能を提供しているかをXMLで記述した仕様書です（×）。
