## 0. 一枚で：名前を2つに割って一発暗記！

「サイバーフィジカルシステム（CPS）」は、英語を半分に割るだけで中身が丸見えになります。

```
サイバー  ＋  フィジカル
 (電脳・仮想)    (肉体・現実)
```

現実（フィジカル）と仮想（サイバー）の間で、データを **「卓球のラリー（往復）」** させる仕組みのことです！

---

## 1. 卓球のラリー（3ステップの往復運動）

CPSの決定的な特徴は、**「一方通行ではない」** ということです。必ず現実の世界にボールが跳ね返ってきます。

```
【第1球：サーブ】
［現実］畑の土壌センサーが「土が乾いてきたよ！」と計測する（データ収集）
   │
   ▼
【第2球：ラリー】
［仮想］クラウドのAIが「30分後に雨は降らないから、今すぐ水が必要だ！」と計算する（分析・加工）
   │
   ▼
【第3球：スマッシュ】★ここがCPSのキモ！
［現実］畑のスプリンクラーが自動で開いて、ジャーッと水を撒く！（現実へフィードバック）
```

ただ画面に「土が乾いています」とグラフを出すだけ（一方通行）は、CPSとは呼びません。  
**「分析結果をもとに、現実の機械を自動で動かす（フィードバックする）」** ことで完結します。
