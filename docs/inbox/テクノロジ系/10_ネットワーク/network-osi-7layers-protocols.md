> **想定読者**: 「トランスポート層」「ネットワーク層」「アプリケーション層」と言われても、どのプロトコル（HTTP, IP, TCP, UDP）がどの階に住んでいるのか迷ってしまう文系受験者  
> **省いたもの**: セッション層とプレゼンテーション層の歴史的細かい規格（OSIとTCP/IPモデルの4層/7層論争）  
> **所要時間**: 7分  
> **対象過去問**: 応用情報技術者 令和5年春期 午前問34

## 0. 一枚で：7階建てマンションの「住人一覧」！

インターネットの通信は、**「役割ごとに階が分かれた7階建てビル」** です。  
試験で出るプロトコルは、どの階に住んでいるか決まっています！

```
┌──────────────────────────────────────────────┐
│ 【7階】アプリケーション層（人間の目に見える） │ HTTP, HTTPS, SMTP(メール), DNS, FTP
├──────────────────────────────────────────────┤
│ 【6階】プレゼンテーション層（データの翻訳）   │ 文字コード, JPEG, SSL/TLS(暗号化)
├──────────────────────────────────────────────┤
│ 【5階】セッション層（会話の開始と終了）       │ 対話の管理
├──────────────────────────────────────────────┤
│ 【4階】トランスポート層 ★（配達の責任者！）  │ ★【TCP と UDP の2人だけ！】
├──────────────────────────────────────────────┤
│ 【3階】ネットワーク層（住所と道案内）         │ IP, ICMP(ping), ルータ
├──────────────────────────────────────────────┤
│ 【2階】データリンク層（隣の機器へ渡す）       │ Ethernet(LAN), Wi-Fi, MACアドレス
├──────────────────────────────────────────────┤
│ 【1階】物理層（電気や光の信号）               │ LANケーブル, コネクタ, 電波
└──────────────────────────────────────────────┘
```

👉 **最重要暗記フック：『 4階（トランスポート層）の住人は、TCP と UDP だけ！ 』**  
「トランスポート層に位置するものはどれか？」と聞かれたら、**選択肢から「TCP」か「UDP」を探すだけ** で0秒で解けます！

## 1. 7階層の語呂合わせ（下から順）

昔からの定番語呂合わせ：  
**『 ア・プ・セ・ト・ネ・デ・ブ 』**（上から）  
または下から：  
**『 ぶ・で・ね・と・せ・ぷ・あ 』**

1. **物（ぶ）** 理層
2. **デ** ータリンク層
3. **ネ** ットワーク層
4. **ト** ランスポート層（★TCP / UDP）
5. **セ** ッション層
6. **プ** レゼンテーション層
7. **ア** プリケーション層（★HTTP / SMTP / DNS）

---

## 2. 選択肢のプロトコルたちの所属部屋

令和5年春期 問34の選択肢に出てくる4人の住処を整理します：

- **ア: HTTP**: Webサイトを見るためのもの $\rightarrow$ **7階（アプリケーション層）**
- **イ: ICMP**: pingコマンドで相手が生きてるか調べるもの $\rightarrow$ **3階（ネットワーク層・IPの相棒）**
- **ウ: SMTP**: メールを送信するためのもの $\rightarrow$ **7階（アプリケーション層）**
- **エ: UDP（正解！）**: 荷物を速達で投げるもの $\rightarrow$ **4階（トランスポート層）**

## 4. 実際の過去問で腕試し

### 【午前過去問】令和5年春期 午前問34
**【問題】**  
IPネットワークのプロトコルのうち，OSI基本参照モデルのトランスポート層に位置するものはどれか。

- **ア**: HTTP
- **イ**: ICMP
- **ウ**: SMTP
- **エ**: UDP

<details>
<summary>正解とスピード解法を表示</summary>

**正解: エ**

**文系目線でのスピード解法:**
- 「トランスポート層（4階）」と来たら、住人は **TCP** か **UDP** の2択！
- 選択肢を見ると、**エ** に「UDP」がいるので、問題文を読んだ瞬間に即決できます！
- HTTPとSMTPは人間が使うアプリ（7階）、ICMPはIPの相棒（3階）です。
</details>
