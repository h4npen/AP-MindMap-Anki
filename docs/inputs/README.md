# 📥 過去問道場 結果ファイル投入フォルダ (`docs/inputs/`)

このフォルダは、**過去問道場（応用情報技術者試験ドットコム）で間違えた問題の結果ファイルやメモを投入する場所** です。

---

## 🛠️ 使い方・運用フロー

1. **間違えた問題を投入する**:
   - 過去問道場の演習結果CSV / JSON
   - 間違えた問題のスクリーンショット画像（`.png`, `.jpg`）
   - 間違えた問題番号やメモ（例: `R4秋_問14.txt`, `復習リスト.md`）
   など、形式は何でも構いません。

2. **AI（Antigravity）に作成を依頼する**:
   - チャットで **「inputsに入れたファイルを見て、新しい解説ノートを作って」** と伝えるだけ！
   - AIが自動で `docs/README.md` の **「解説ノート作成ルール」** に従って `docs/inbox/<単元名>/` 配下にスマホ最適化された解説MDを生成します。

3. **学習と整理**:
   - 生成されたノートはまず `docs/inbox/` に格納されます。
   - 通勤中などにスマホで読み、理解できたら `docs/ap-prep/` へ移動してストックします。
